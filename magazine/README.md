## 편집 원칙

사실은 확인 가능한 출처나 명시된 계산에 연결한다. 여러 관측을 묶은 설명은 **추론**이라고 밝힌다. 가치판단은 **의견**, 아직 데이터가 없는 설계나 전망은 **가설·추측**으로 표시한다. 상관관계를 인과로 승격하지 않으며, 개인 취향과 국가적 자부심을 기술적 결론의 근거로 쓰지 않는다. 결론마다 경쟁 설명과 “무엇이 이 결론을 바꿀까?”를 남긴다.
