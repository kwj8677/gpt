# Relational–Event Packaging across Northern Eurasia and the Indigenous Americas

한국어·일본어·몽골어·튀르키예어·핀란드어·헝가리어와 북·남미 원주민 언어 표본에서 반복되는 형태통사적 패턴을 비교한 가설 중심의 working paper입니다.

## 핵심 주장

이 프로젝트는 해당 언어들이 하나의 거대 어족이라는 주장을 하지 않습니다. 대신 다음을 검증 가능한 가설로 제안합니다.

> 북유라시아와 아메리카의 여러 언어는 ‘사물의 고정 분류’보다 ‘사건 안에서 참여자·방향·정보 출처·담화 중심을 추적하는 것’에 더 많은 문법 자원을 배분하는 경향을 보인다.

이를 **REPS(Relational–Event Packaging System)**라는 비교 모형으로 정리했습니다.

- 북유라시아형: 접미·격·조사·후치사 중심의 **종속표지형 조립**
- 베링기아형: 강한 접미성과 높은 종합성을 잇는 **교량형**
- 북미 다합성형: 동사 내부의 인칭·논항·분류·방향 표지 중심의 **핵표지형 압축**
- 안데스·아마존형: 접미·증거성·담화·공간 표지가 결합한 **혼합형 고밀도 부호화**
